# Метаданные модуля (modinfo)

Команда modinfo ./hello.ko показывает путь к файлу, имя модуля, описание, автора, лицензию и прочие поля. Это подтверждает, что hello.ko собран и содержит корректные записи для загрузчика модулей.

# Загрузка и проверка в списке модулей

Модуль загружается от имени суперпользователя: sudo insmod hello.ko. 

Наличие в ядре проверяется, командой 
lsmod | grep hello

# Журнал ядра при загрузке и выгрузке

sudo rmmod hello (модуль успешно выгружен)
