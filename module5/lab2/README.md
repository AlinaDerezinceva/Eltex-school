# Загрузка и проверка

sudo insmod proc.ko
lsmod | grep proc
ls -l /proc/mymod

На скриншоте: модуль proc присутствует в списке загруженных, файл /proc/mymod создан.

(Screenshots/Load_verify.png)

# Журнал ядра после загрузки

sudo dmesg | tail -n 10

В логе видно сообщение инициализации модуля. Строка о невозможности верификации подписи модуля и «загрязнении» ядра типична для локально собранных неподписанных модулей и не мешает учебной работе.

# Проверка чтения и записи

sudo sh -c 'echo "Hello from proc" > /proc/mymod'
sudo cat /proc/mymod

Вывод cat совпадает с переданной строкой — обработчики write_proc и read_proc отрабатывают.

# Выгрузка

sudo rmmod proc
ls /proc/mymod 2>&1
sudo dmesg | tail -n 5

После rmmod путь /proc/mymod недоступен; в dmesg есть сообщение об успешном удалении узла из функции выхода модуля.
